# AIGC视频创作课程菜单

[在线课程菜单](https://py198964.github.io/aigc-course-menu/)

47门原子课程，75小时课库；13个转绘专题模块。

- 四类课程颜色与文字双重区分。
- 搜索、筛选、课程购物车与顺序调整。
- 前置检查、自动命名、按日排课和简版教案。
- 本地保存、组合JSON导入导出、Markdown教案与打印PDF。
- 已按画布与Redraw教程核对操作路径；P18、P25使用画布动作迁移并以前置T01组课。
- 每门课提供完整简介、目标、分时课纲、练习与评价；F13训练镜头调度。
- 组合后可复制或下载宣传提示词，包含各模块的策划元数据。提示词仅在界面隐藏，公开静态文件可读取，不存放秘密信息。
- 无后端、无外部AI服务，教案按课程大纲规则编排。

GitHub Pages从main分支根目录发布。课程资料日期：2026年9月24日。

## 机构课程平台

`platform/` 是独立的完整业务系统，包含 FastAPI 后端、SQLite 数据库和机构管理前端。支持人员与机构权限、课程版本审核、资源授权、模块参考价、组课与教案、客户询价、项目报价确认，以及规则组课和可配置的 AI 文案接口。

[查看运行与部署说明](platform/README.md)。本机默认地址为 `http://127.0.0.1:8765`；此系统不由 GitHub Pages 运行。
