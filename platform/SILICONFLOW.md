# 硅基流动接入

本版本提供两条流程：手动组课后生成课程名称、副标题、简介、目标、亮点和宣传摘要；根据课程主题生成背景，再用模板排版并下载 PNG 海报。原“规则选课 + AI文案”也会优先使用配置好的硅基流动服务。

## 配置

在服务器环境变量中设置 `SILICONFLOW_API_KEY`；本地也可将密钥单独一行保存在 `COURSE_DATA_DIR/siliconflow.key`，默认目录为 `platform/runtime`。本地文件每次调用时读取，保存后即可使用。不要将密钥提交 Git，不要通过网页前端配置密钥。本地密钥文件不包含在课程数据备份或源码部署包中。

接口固定为 `https://api.siliconflow.cn/v1`。课程文案固定使用 `Qwen/Qwen2.5-7B-Instruct`（不含 Pro 前缀），背景使用 `Kwai-Kolors/Kolors`。2026-09-29 官方价格页均标为免费；实际以服务商最新政策与账号权限为准，软件不能保证服务商未来不调整价格。不会自动换模型或使用付费备用模型。最初候选 Xing4.0-29B 多次调用超时，因此没有作为首版文案默认模型。

## 使用

1. 登录并选择课程，进入“课程组合”。
2. 填写培训对象与重点，点击“AI生成课程信息”。
3. 在结果预览中勾选需要采用的字段，点击“应用选中内容”；继续编辑，点击“保存方案”。目标、亮点等字段会随方案版本及 JSON / Markdown 导出保存。
4. 点击“制作宣传海报”，选择院校研修、企业内训或社会招生模板；可编辑标题、机构、亮点、报名说明，上传本机二维码用于排版。
5. 可直接下载纯模板海报，也可点击“生成AI背景”。成功后点击“用于当前海报”，再下载 1080×1440 PNG。AI背景由服务端保存，海报文字和二维码在当前浏览器排版，不再调用模型。最终 PNG 下载到本机；本阶段服务端留存的是背景及文案任务，不是海报排版工程。
6. “宣传素材”可以查看当前账号、当前机构最近 30 个任务；刷新或关闭生成弹窗不丢失任务。使用历史结果前需载入对应课程组合。重新生成是新任务，不覆盖原结果。

## 运行约束

- 文案输入仅包含经权限与课程版本校验的模块标题、描述、目标、成果、时长，以及培训对象和需求重点；不发送账号密码、联系方式或模块隐藏提示词。
- 输出通过字段、类型和长度检查；文案仍需机构复核后使用，不自动替换手工内容。
- 每账号滚动 24 小时最多 10 次文案、3 次背景；每机构共用 `agent_daily_limit` 作为本功能的滚动 24 小时总量上限。失败也计次数；同一请求标识重复提交不会再次发起模型调用。单账号最多同时两项任务。
- 数据库保留任务及明确的失败状态。当前采用应用进程内后台任务；服务重启可能中断在途调用，超过 10 分钟会标记为中断，不自动重试计费请求。
- 图片临时 URL 只用于服务端下载，限定官方服务/CDN HTTPS 域名，不跟随重定向，不向下载域名发送 API Key。文件大小上限 12MB，仅保存 PNG/JPEG/WebP，并通过登录及课程可见性校验提供下载。
- API 请求使用直连，避免继承本机系统代理造成超时。需要企业代理的部署应显式调整网络配置。
- GitHub Pages 公开站提供本地模板海报；真实 AI、任务历史和账号权限仍由完整后端提供。

官方资料：[价格](https://siliconflow.cn/pricing)、[会话接口](https://docs.siliconflow.cn/docs/api/chat-completions-post)、[生图接口](https://docs.siliconflow.cn/docs/api/images-generations-post)。
