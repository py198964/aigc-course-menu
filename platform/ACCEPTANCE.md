# 第一阶段验收记录

验收日期：2026-09-28。环境：Windows、Python 3.12、Microsoft Edge 无头浏览器。

## 自动化结果

后端 **15 项测试通过**，覆盖：

- 47 门 / 75 小时课程迁移、各课纲分钟数和全部先修关系有效，公开 API 不返回内部提示词。
- Cookie 会话、CSRF 和来源校验；客户越权失败；平台管理员无法直接读取其他机构私有数据。
- 指定邮箱邀请、讲师不能自审、讲师不能编辑他人模块、停用成员即时失去机构权限、最后负责人保护。
- 草稿不能公开，审核后才发布；公开附件与发布版本绑定；修订复制附件仍需审核；并发编辑不覆盖新版本。
- 客户询价幂等、跨客户隔离、项目附件授权；改价不改变历史需求快照，报价小计仍按原版计算。
- 草稿报价对客户不可见，管理员发送后客户可确认；重复确认幂等，已确认报价阻止后续覆盖。
- 六类主题（转绘、短剧、口播、广告、教学、综合）的规则组课：预算、天数、完整模块容量和先修顺序校验。
- 私有方案导出隔离；非法课纲、循环依赖与超预算必选项处理。
- AI 成功响应以模拟接口验证，生成文案可随方案保存；外部服务失败明确回退为规则模式。
- 初始化幂等和数据库备份。敏感数据路径不能通过静态网址访问。

浏览器实际点击验收通过：

- 课程菜单、登录注册、工作台、邀请、创建课程、上传资料、提交审核、发布。
- 客户选课、方案保存、询价、规则组课、机构报价、正式发送、客户确认、历史方案载入。
- 新版 JSON 导出/导入保留自定义简介；旧版 aigc-course-plan/v2 文件兼容；课程关系查看及组合模板载入。
- 320、390、768、1024、1440 像素布局检查；页面无横向溢出；流程中无未捕获 JavaScript 异常。

正式本机实例也已执行启动、停止、重启、健康接口检查和真实数据库备份，PID 与监听进程一致。正式数据只包含初始机构、负责人和 47 门课程；验收账号与询价使用独立数据库。
